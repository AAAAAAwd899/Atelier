# Install Atelier 1.0.17

Use Tools → Add-ons → Install from file and choose Atelier-1.0.17.ankiaddon, then restart Anki. This one file is all a recipient needs. Update your existing Atelier installation; do not delete its saved work or install a second copy.

The real Anki toolbar is kept visible above Atelier’s home, including native add-on actions. Appearance opens themes and compatibility settings; its Anki toolbar switch lets an existing hide policy take over again on redraw. Fullscreen, native/original appearance and review keep their own behavior. Atelier does not install a different version of the Anki application.

The updated Onigiri restaurant header/body layout preserves the installed add-on’s art, controls and rewards. Onigiri must be installed separately; no XP or settings are reset. Retain your collection backups plus Atelier user_files, exam_sprout and workshop profile folders. The tested 1.0.16 installer is the rollback; back up new work/preferences before downgrading.

Online Friends remains unconfigured. This patch is not an AnkiWeb upload. See the matching Build JSON and Evidence ZIP for current verification and limits.
