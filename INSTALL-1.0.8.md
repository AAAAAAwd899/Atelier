# Install Atelier 1.0.8

The complete install/send file is `Atelier-1.0.8.ankiaddon`. In Anki desktop choose Tools → Add-ons → Install from file, select it, and restart. Update the existing Atelier installation; do not delete its saved files. The source and evidence ZIPs are for review, not installation.

To reorganize: open Library, use a folder/deck's three-dot menu → Move to another folder (or right-click → Move…). Search for a destination or browse folders. All folders at the start of the path means top level. Check From and To, then choose Move here. Cancel makes no changes. Drag-and-drop also opens this confirmation.

A moved folder keeps its descendants and card IDs. Parent-based exam/study selections follow their current contents, so moving between courses can change what those parent selections include. A new parent's daily limits can affect available scheduled cards. Use Edit → Undo promptly to reverse the move before doing another operation.

Keep a normal collection backup and preserve Atelier user_files plus the profile-local workshop and exam_sprout stores. No numeric AnkiWeb identity or automatic migration is invented. Public AnkiWeb upload remains an owner action after the exact listing exists.
