# Atelier 1.0.7

Adds **Add-on tools**, a searchable native window reached from Anki tools or Tools → Atelier. It opens original Tools/add-on menu actions, keeps their shortcuts and enabled/checkable behavior, and refreshes commands added later. It closes cleanly with the profile. No third-party add-ons are installed, bundled or reconfigured. Their editor buttons and reviewer widgets stay in their original interfaces.

Retains the cumulative 1.0.6 clock, 13-step orientation, task guide, approved artwork, full-folder shuffle, masks, card/exam engines, stores and optional widget integration. See the version-matched audit for evidence and compatibility limits.
