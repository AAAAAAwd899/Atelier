Version 1.0.3 · Private review

One study workspace

Browse nested lecture folders, return to saved work, create source-based drafts in Card Studio, and prepare with Exam Studio. Twelve visual worlds, built-in widgets and the original Anki tools remain available.

Cards are added only through the existing review and approval flow. Normal Anki review changes your schedule. Independent practice and optional new-card learning retain their explicit mode labels.

Installation and updates

AnkiWeb distribution is being prepared. There is no public add-on code or download yet.

When the owner approves a release, the listing will include the exact add-on code, installation instructions, tested Anki versions and recovery guidance. Existing private installations will need a verified one-time transition to the numeric AnkiWeb identity.

Future approved versions will be uploaded to that same AnkiWeb listing. This page does not install updates or change your collection.

Your work stays under your control

Atelier's local source, exam and widget stores are separate from your Anki collection. Back them up separately; Anki Sync does not include them. This visual upgrade adds no telemetry or remote fonts.

Compatibility and native test evidence will accompany the approved installer. macOS and physical remotes are not advertised as verified.
