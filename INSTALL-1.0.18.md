# Install Atelier 1.0.18

In Anki, choose Tools → Add-ons → Install from file, select Atelier-1.0.18.ankiaddon, then restart. This is the only file a recipient needs. It updates the existing Atelier installation; do not delete its saved work or install a second copy. The original native toolbar is retained on home, overview and review when enabled in Appearance. Compact action labels keep all routes visible. Anki updates uses the application’s existing update check; it does not invent a launcher/version selector. Onigiri remains separately installed, with its own existing startup warning disclosed in the evidence. Online Friends hosting and AnkiWeb publication remain separate, unperformed actions. Keep collection and add-on work backups before changing versions; tested Windows 1.0.17 is the rollback.
