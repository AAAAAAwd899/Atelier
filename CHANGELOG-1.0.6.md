# Atelier 1.0.6

- Adds a small world-matched Study clock: countdown, stopwatch, pause/resume, reset, optional finish sound and keep-on-top. Open it from the top bar or Tools → Atelier. Closing its window keeps the clock running; closing the profile saves it paused. It never modifies Anki scheduling or study statistics.
- Extends the optional guided tour to 13 steps and adds a replayable Getting started guide with ten practical task recipes, including slidesets, image occlusion, exact study scope, combined-parent exams, sharing and backups.
- Prepares the AnkiWeb title, descriptions, compatibility/support fields, seven genuine native interface screenshots, captions and local preview. No AnkiWeb upload or website deployment occurs.
- Retains the full cumulative 1.0.5 upgrade, original-theme compatibility, whole-folder native shuffle, saved work, masks, exam/card engines, remote routes and native widget integration. Public support uses the owner-authorized Atelier GitHub repository.
