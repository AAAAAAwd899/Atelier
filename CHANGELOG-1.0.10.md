# Atelier 1.0.10

- Set exam is available directly on folder and deck rows, including the Folder tree. An active exam is labelled Exam active. Existing independent and combined study scopes remain supported.
- Arrange order saves a separate display order for All folders and each parent folder. Move items up, down or to the top, then Save order. Cancel discards the draft. Restore name order resets only that folder.
- My order is available alongside Name, Review / learning and Recent. Newly added items follow saved items. A changed folder membership during editing prompts a fresh arrangement rather than saving a stale list.
- Display ordering does not rename or move decks, alter cards or change Anki scheduling. Existing art, engines, masks, remotes, widgets and original-theme support are retained.
