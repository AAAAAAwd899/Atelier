# Getting help with Atelier

## Start with the recovery controls

Save your work first. For an appearance problem, open **Tools → Atelier** and choose the original-home or original-reviewer option. If needed, disable Atelier in **Tools → Add-ons** and restart Anki. Disable rather than delete the package to keep local preferences.

Keep separate Exam Sprout and Workshop copies disabled while using the combined Atelier. Before rolling back, back up the collection and all three local data areas listed in **USER-GUIDE.md**.

## Send a useful report

Report an ordinary bug at https://github.com/AAAAAAwd899/Atelier/issues/new/choose. Include the Atelier version from Tools, the exact Anki version, Windows display scaling, the selected appearance owner/world, and the shortest steps that reproduce the problem. Describe what you expected and what happened. A screenshot is useful when the issue is visual.

**Copy display diagnostics** can help identify the open screen and loaded version. Reports are not sent automatically. Read a report before sharing it, remove private paths or content, and never share an API key. Do not send your collection, original source documents, or full profile folders unless you deliberately agree to share them.

Explain whether the problem also occurs in a spare profile or with other optional add-ons disabled. Do not delete or reset your real data just to troubleshoot.

## Before updating

Finish or **Save & close** practice, save authoring work, and wait for imports/publishing to complete. Close Anki before copying backup folders. Reopen Anki, install the new `.ankiaddon` over the existing version, then fully restart again.

Updates supplied as files use the same installation identity. This release does not include a separate automatic updater or a public AnkiWeb installation code.
