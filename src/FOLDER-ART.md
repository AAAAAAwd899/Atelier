# Atelier folder symbols — 1.0.12

`web/folder-icons-1.0.12.png` is one 1536×1024, six-column/four-row raster atlas generated for Atelier using the built-in image-generation tool. It contains 24 decorative study/personal symbols, not clinical reference illustrations. It is not copied from Onigiri or a branded icon library. The original eighteen stored token identities remain valid; six choices are additive. Automatic chooses books for a folder and notes for a lecture deck. Local asset failure retains the original automatic glyph or the selected symbol's emoji fallback.

Direction: tactile ceramic, warm paper and brass, consistent studio light and legible silhouettes at small size. The first pass was refined to remove broad background haze. The delivered RGBA asset was inspected on an actual dark UI panel and in light/dark and compact release captures with packaged assets resolved. No labels or controls are baked into the artwork. Selection, focus, saved state and color markers are native application markup/styles.

Generation prompt and source SHA-256 are recorded in the matching source's ASSET-PROVENANCE-1.0.12.json. Generated assets are not represented as exclusive copyrighted or independently trademark-cleared work.
