# Install Atelier 1.0.13

In Anki choose Tools → Add-ons → Install from file, select Atelier-1.0.13.ankiaddon, then restart. Send only this installer to another user. It replaces the same Atelier package; do not enable a second copy.

Folder menu → icon and color opens the updated picker. Hover or focus an object with the keyboard to see its brief movement; click/tap to save. The selected wash and checkmark remain after motion finishes. Reduced motion or Atelier motion-off disables decorative motion. All organization, study, authoring and sharing features are retained.

Keep the tested 1.0.12 rollback. Do not delete profiles or add-on user_files. This is a manual installer; no AnkiWeb code or automatic update channel has been created.
