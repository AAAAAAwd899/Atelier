# Install Atelier 1.0.16

Use **Atelier-1.0.16.ankiaddon** in Anki desktop: **Tools → Add-ons → Install from file**, select the file, then restart Anki. You can send that one installer to someone else. Source, evidence and service files are separate and are not required for installation.

Keep the same private package identity `daedalus_atelier`. Back up the Anki profile and Atelier `user_files`, `exam_sprout` and complete `workshop` folders before any update. Do not delete earlier add-on data to change appearance. The normal cumulative upgrade retains decks, schedules, source projects, saved drafts/practice, masks, widgets, remotes and preferences. Separate old standalone Exam Sprout/Workshop installations remain disabled without deleting their data.

Open **Tools → Atelier → Companion journey** for the new local keepsakes, or **Friends & shared folders** for offline sharing and the prepared optional online window. These Tools entries also work with Atelier visuals off. The installer does **not** contain a connected Friends server; online signup/invites/uploads cannot be used until the operator completes the separate hosting/approval requirements in the matching source. No AnkiWeb account/login is required for local features.

Native evidence is labelled by actual Anki version/profile and Qt-offscreen scope in AUDIT-1.0.16.md; do not infer macOS/Linux, every third-party add-on, physical remote or hardware-GPU certification. Installation/publication on a future numeric AnkiWeb listing still requires its real listing ID and migration test. This file is not an AnkiWeb publication or automatic-update activation.

The tested rollback is 1.0.15, which understands the same saved-data formats. Keep normal collection/project/settings backups; rolling back restores the older greenhouse-focus and Friends-reopening behavior. Do not remove saved work to change versions.
