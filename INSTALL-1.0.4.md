# Install Atelier 1.0.4

In Anki, open **Tools → Add-ons → Install from file**, choose `Atelier-1.0.4.ankiaddon`, then restart Anki. Updating the existing `daedalus_atelier` installation keeps its private identity; do not delete the old add-on first. Back up your Anki collection and Atelier saved-work folders before any update.

If Onigiri is installed, open the Study desk and choose **Show rewards**. The live restaurant, activity grid, and reward controls come from Onigiri; the browser fixture screenshots in this package intentionally use placeholders. If the embedded view misbehaves, use **Widgets → More tools → Original Onigiri page · compatibility**.

To roll back, reinstall the retained Atelier 1.0.3 installer over the same private identity and restart. Disable Atelier in Tools → Add-ons to return to Anki's original interface. This local file is not an AnkiWeb listing and cannot update other users automatically; that requires a later approved AnkiWeb publication with a numeric listing ID.
