# Install Atelier 1.0.14

In Anki choose Tools → Add-ons → Install from file, select Atelier-1.0.14.ankiaddon, then restart. Send only this installer to another user. It updates the same Atelier package; do not enable duplicate copies.

Open Worlds or the appearance palette. Hover or keyboard-focus any scene to see its short response. Click/tap to choose it. Selected styling and the saved theme remain after motion settles. Use Atelier motion-off or your system reduced-motion preference for a static chooser.

All existing library, study, authoring, widget and sharing features remain available. Keep the tested 1.0.13 rollback. Do not delete profiles or user_files. This remains a manual installer without an AnkiWeb code or automatic-update channel.
