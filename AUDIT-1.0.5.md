# Atelier 1.0.5 private installer audit

This cumulative update adds optional onboarding to the cumulative 1.0.4 interface and workflow. Twelve steps explain the actual library, study scope, card sets, native editor, multi-parent exams, practice, Pip, progress, tools, widgets and worlds. The tour highlights controls without invoking collection operations. It supports Back, Escape, keyboard focus, small windows, explicit first tasks and replay from the workspace or native Tools menu. Only a validated profile-local help marker is persisted. Original/other-add-on appearance ownership does not receive an automatic tour.

The minimum Anki version is declared as 25.09.5. This is a package requirement, not evidence of all possible host combinations. The configuration schema now contains all 17 existing worlds. No scenery, companion or panel artwork was replaced for this update. Whole-folder shuffle, native scheduling, original-theme access, masks, remotes, saved work and both bundled engines remain part of the cumulative installer.

The only engine dependency update is namespaced pypdf 5.9.0 to official 6.21.1, following published resource-exhaustion advisories. `PYPDF-VENDOR-6.21.1.json` pins the official wheel hash, every upstream file, every shipped file and the relative-import adjustments. Four obsolete private parser modules are retired. Historical tests retain exact baseline parser bytes as source-only fixtures; current dependency tests separately verify every new shipped byte, namespace isolation, real multi-page PDF text/order and the decompression limit. Importer, publisher, mask, storage and assessment code outside that scoped dependency remains protected by the original preservation assertions.

The actual `.ankiaddon` format gate checks entry points, package identity, minimum version, ZIP integrity, notices and excluded private data. `ANKI-ADDON-COMPLIANCE-1.0.5.md` records the official sources and the limits of this review. It is not AnkiWeb certification, a legal opinion or public release approval.

Current automated and native receipts are generated in `verification/` and `output/native-*-105/` and summarized in the final build manifest. Browser fixtures are explicitly synthetic. In particular, the Onigiri fixture omits restaurant artwork and is not evidence of a live restaurant render. Native Anki/Qt tour captures contain synthetic records and use software rendering at the recorded Windows display scale.

Unperformed gates remain explicit: macOS, physical remotes, live GPU Pip, uncoached onboarding, every card template and every third-party add-on combination. Public AnkiWeb eligibility, listing identity/migration, upload acceptance and an approved website destination remain pending. An installable private package cannot automatically update everyone through AnkiWeb.

The final runtime fingerprint is `8ec073dd513286ad28764006c70df461628ee0faa5743da1064aad5aed1c0fe6`. Current receipts record 1,920 passing Python checks and 2,881 Chromium checks across 30 suites. The release-finish fixture initially checked IntersectionObserver delivery after a fixed 200 ms delay; it now waits for the first request while retaining the strict fewer-than-30 lazy-loading assertion. All 82 checks passed on the final rerun; other suites are from the fresh cumulative run.

Actual installed Windows Anki 26.09.3 passed 53 native checks: 10 installer/preservation, 25 tour/collection/persistence, 8 native folder-order/Undo and 10 image-occlusion/rendering/grading/Undo checks. These use the installed MSI's Anki/Qt packages through a pre-existing compatible CPython 3.13 interpreter, with software rendering and unsynced disposable profiles. The image-occlusion harness was corrected to wait for Anki's initial document before switching to review; its final run has no uncaught JavaScript error. Chromium reports warnings concerning the inherited body aria-hidden isolation when accessibility inspection is active; the native accessibility tree exposed the guide and its controls. No accessibility-conformance certification is claimed.

Qt widget/screen grabs proved unreliable in the helper desktop and were rejected. Their hashes/rejection reason are retained in `screenshots/native-onboarding-105/capture-review.json`; generated images were reclaimed. The accepted native tour image is the visually reviewed foreground computer-use JPEG of the real Study scope guide. Native DOM geometry receipts and high-resolution browser fixture screenshots are separately labelled. The fixture screenshots are not the owner's collection or live Onigiri.

Anki itself was updated from the older installed host to official 26.09.3. Its MSI signature was valid and its SHA-256 matched GitHub's official release digest. The local pre-update collection/Atelier backup passed readback hashes and collection structural quick-check. This private backup is excluded from source, installer and evidence archives. The owner elected to install Atelier 1.0.5 manually; this delivery does not claim it was installed into the owner's real profile.
