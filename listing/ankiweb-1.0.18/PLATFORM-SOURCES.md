# Platform facts checked for this handoff

- Official packaging/manifest guide: https://docs.ankiweb.net/addons/sharing . An `.ankiaddon` is a ZIP with files at its root, no enclosing add-on folder or `__pycache__`. Outside AnkiWeb, the manifest supplies `package` and `name`.
- Official user instructions: https://docs.ankiweb.net/addons.html . Anki updates can change add-on compatibility; desktop add-ons are separate from mobile/web study interfaces.
- Maintainer clarification that description text is interpreted as Markdown: https://forums.ankiweb.net/t/add-on-description-mess-up/33165 . The actual signed-in submission editor was not exercised; preview before publishing.
- Updating the existing listing: https://forums.ankiweb.net/t/how-to-update-my-existing-add-on/9135 . Its Update form accepts the replacement installer; retain the same listing identity.
- Account-age clarification: https://forums.ankiweb.net/t/my-anki-account-is-not-old-enough-for-add-ons/67649 . The sharing/upload restriction is separate from installing an add-on locally. This handoff does not assert that the owner’s account is now eligible.
- Maintainer’s 2024 approximate add-on upload limit: https://forums.ankiweb.net/t/how-many-mb-is-the-limit-for-the-add-on-file-that-can-be-uploaded-to-ankweb/39069 . This is historical guidance, not proof of the current signed-in upload limit. The actual final file size is in upload-checks.json; upload acceptance remains unperformed.

No terms, account creation, AnkiWeb upload, public binary release, website deployment or Friends hosting action was performed by preparing this kit.
