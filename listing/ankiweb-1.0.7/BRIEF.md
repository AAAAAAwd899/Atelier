# Listing and study-clock review brief

Audience: people using Anki desktop for courses, self-study or exam preparation, including learners unfamiliar with add-ons. Primary path: install, take/skip orientation, import or select existing material, organize a study scope, create/study cards, then return to unfinished work.

Voice: calm, concrete and helpful. Keep the product name Atelier. Avoid claims of better grades, superior retention, verified universal compatibility, account eligibility or Anki endorsement. Distinguish organizing material from merging decks and normal scheduled review from practice.

Art direction: preserve the approved authored scenery and interface; use the existing world scene and palette in a small, readable native clock. No new decorative art, logo, canvas/SVG scenery or promotional UI image. Native original appearance ownership retains ordinary Qt styling. Desktop and compact states, pause/finish/reopen, and task help must remain usable.

Onboarding scope: the tour orients; the Getting started reference supplies ten task recipes. Neither substitutes for a fully observed novice study. Replay is always available. Do not promise that every specialized third-party editor is recreated inside Card Studio.

Screenshots: prefer actual Anki webviews and native clock with deliberately created example data. Never use the owner's collection or source files. Label synthetic browser fixtures if any are needed. Show genuine empty/history states rather than invented activity. Preserve controls and functionality while framing the images. Do not include third-party Onigiri restaurant art in the listing assets.

Publication: public source/support repository explicitly authorized by the owner on 2026-10-20. Website deployment, AnkiWeb account access and final listing publication are not authorized by this preparation task. Verify current source, history, notices, fields, actual images and external links before visibility change.

Storage budget: existing headroom about 164 GiB before this pass; allow up to 2 GiB for current/rollback installers, one bounded set of disposable native profiles, source/evidence/owner handoffs and screenshot renders. No full source-tree snapshots. Keep the previous 1.0.5 installer and owner recovery backup protected.

1.0.7 scope: add original-command discovery without replacing third-party menus, settings, embedded controls or shortcuts. Keep the accepted home visuals and engines. Inspect the real native window and updated Tools page. Native menu-provider tests are not named-add-on execution.
