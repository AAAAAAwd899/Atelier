## Updating people later

For people who install through AnkiWeb, publish future versions through **the same listing’s Update action**. Anki’s usual update checks then apply. Creating another listing produces a separate identity.

A manual installation currently uses `daedalus_atelier`. Its automatic migration to a future numeric AnkiWeb installation is **not verified** because no real code exists yet. Keep existing projects and preferences backed up, avoid running duplicate Atelier installs, and obtain verified migration instructions before switching existing users. Do not delete their data to make a clean screenshot or install.
