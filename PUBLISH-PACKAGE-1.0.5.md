# Atelier 1.0.5

## Install or send now

Send `Atelier-1.0.5.ankiaddon`. Recipients install it in Anki desktop using **Tools → Add-ons → Install from file**, select the file and restart Anki. Keep an existing Atelier installation in place while updating. Back up the collection and Atelier saved-work folders first. An AnkiWeb listing is not required for this direct installation.

The first-run guide can be skipped and replayed from **Tools → Atelier → Guided tour**. The existing worlds, card/exam engines, image occlusion, folder shuffle and original-theme access are included.
