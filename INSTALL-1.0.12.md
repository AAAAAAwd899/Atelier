# Install Atelier 1.0.12

In Anki, choose **Tools → Add-ons → Install from file**, select **Atelier-1.0.12.ankiaddon**, then restart Anki. Send this single file to someone who wants to install it. It replaces the same Atelier package; do not enable a second copy.

Use **Open full library** above the sidebar folders to browse on the main screen. **Open all folders** reveals the hierarchy; a course's layered icon reveals that course's lectures. Folder names open their contents. **Arrange order** saves a separate display order for each course and the top level. **Set exam** adds that exact folder to active studies.

A folder's three-dot menu retains rename, move, export/share, deck options, icon and color controls. The appearance preview shows saved choices. A parent includes its descendants when studying; no deck or card is merged by browsing or personalization.

Keep an Anki backup and the prior installer. To roll back presentation, install Atelier-1.0.11.ankiaddon over this package and restart. Do not delete the profile or add-on user_files. Rolling back can reset the six newly added icon choices to Automatic; original icon choices and study data are preserved. Anki's Tools menu and original-theme compatibility controls remain available. The AnkiWeb listing/code does not yet exist; this file is a manual installer, not an automatic-update channel.
