# Atelier 1.0.4 private installer audit

Scope: a cumulative update to the verified 1.0.3 candidate. The changed behavior is the optional live Onigiri grid on the Study desk and the active-study folder picker. The installed 1.0.3 copy inspected during this fix lacked the embedded grid packing rules present in the source candidate, explaining the owner's older large-gap screenshot. Version 1.0.4 makes the corrected source distinguishable at install time and retains saved tile widths while releasing full-page row coordinates.

The study picker ranks newly observed folders and card creation IDs, propagating the newest score to parent folders. Cards imported with older IDs do not gain a false import date; older material falls back to natural names. This is a read-only bulk query with one result per deck, run inside Anki's existing background collection snapshot. If that optional query is unavailable, the picker still loads using observed folders and names. The ordering, multi-parent overlap count, field geometry, and desktop/mobile render are checked in a separate browser fixture.

The Onigiri routing browser test uses a synthetic provider-shaped fixture and checks the gap between the last metric and Favorites, side-by-side Favorites/activity widths, readable text in the fixture, six viewport widths, node identity, original event handlers, and restoration of the provider view. Its screenshots are **not** live Onigiri or native Anki captures. The owner's real screenshot shows Onigiri's restaurant artwork; fixture artwork is intentionally omitted. See `verification/widget-routing/results.json` for the current count and errors after the final run.

The current runtime fingerprint is `0ff013ade19a8822d8d6faf7d1a7fac86e3ba1c359fc297a551f7a6655973fd3`. `verification/verified.json` records 1,904 passing Python checks and 2,679 passing Chromium checks across 29 suites. One usability run timed out while a post-publish dialog was closing; it passed all 139 checks on rerun after the test waited for the dialog to close. The current receipt aggregates that rerun with the other freshly executed suites. The 1.0.3 audit remains historical.

`output/native-install-104/results.json` records an actual Anki 26.05 AddonManager update from the verified 1.0.2 baseline to this 1.0.4 installer in a disposable profile. Ten checks passed: update acceptance, exact runtime bytes, private identity, saved preferences and saved-work markers, no install conflict, clean shutdown, and collection SQLite integrity. Temporary test profiles and the baseline transport copy were reclaimed after Anki exited. This does not exercise the owner's real collection or prove live Onigiri's restaurant layout, every add-on combination, macOS, physical remotes, or uncoached usability.

The sendable installer, matching source archive, file manifest, and SHA-256 receipt are in `dist/`. Public publication and AnkiWeb updating remain pending the owner's later decision and listing identity.
