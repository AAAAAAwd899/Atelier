# Install Atelier 1.0.7

Use **Atelier-1.0.7.ankiaddon** only. In Anki desktop choose **Tools → Add-ons → Install from file**, select it, then restart Anki. Do not unzip it or install the full source/listing ZIP as an add-on.

Before updating, back up the collection, the existing Atelier add-on's `user_files`, and the complete profile-local `exam_sprout` and `workshop` folders. Keep existing Atelier installed while updating; do not delete its saved work. Disable standalone Sprout and Workshop because their engines are bundled. Optional Onigiri remains a separate add-on.

Windows Anki 26.09.3 was tested in isolated profiles. The declared minimum is 25.09.5; macOS and Linux were not tested. This package is for Anki desktop, not AnkiMobile, AnkiDroid or the AnkiWeb study site.

Start with the optional welcome tour or **Tools → Atelier → Getting started**. The small clock icon opens a countdown or stopwatch. Timers do not alter cards, scheduling, collection statistics or other add-ons.
