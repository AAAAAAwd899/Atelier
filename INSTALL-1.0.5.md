# Install Atelier 1.0.5

Use **Anki desktop 25.09.5 or newer**. In Anki, choose **Tools → Add-ons → Install from file**, select `Atelier-1.0.5.ankiaddon`, and restart. Back up your collection and saved-work folders first. Keep the current Atelier installation in place while updating; the package identity remains `daedalus_atelier`.

Atelier offers a short guided tour the first time its workspace opens in each profile. Choose **Show me around** or **Skip for now**. Replay it from **Tools → Atelier → Guided tour**, the Anki tools page or the workspace footer. Back moves to the previous step; Escape ends the tour. The guide highlights controls without activating them. The final task buttons open the existing study-folder picker, source importer or library.

The automatic guide respects appearance ownership. In original/other-addon mode it stays out of the way; choose Atelier in Appearance & compatibility to use its guided workspace. The ordinary Anki menus and original editor remain available.

Optional Onigiri rewards stay on the Study desk through **Show rewards**. Its restaurant and controls come from the separate Onigiri add-on.

To recover the original interface, disable Atelier in Tools → Add-ons and restart. The retained 1.0.4 installer is the rollback for this private update. No AnkiWeb listing exists yet: this file can be installed and shared directly, but it does not automatically update everyone. A future numeric listing and identity migration need their own tested, owner-approved release.
